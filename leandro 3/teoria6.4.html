Diferença entre Métodos Get e Set • Método get (Getter): É utilizado para ler ou recuperar o valor de uma propriedade. Ele obrigatoriamente usa a palavra-chave return para devolver o valor solicitado. • Método set (Setter): É utilizado para definir ou alterar o valor de uma propriedade. Ele recebe um parâmetro com o novo valor e não retorna valor (não usa return).
