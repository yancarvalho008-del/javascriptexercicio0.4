Recursos Representados por Objetos em JavaScript Além dos objetos nativos do navegador (como o DOM ou a API de geolocalização), o próprio ecossistema do JavaScript utiliza objetos para representar estruturas essenciais do núcleo da linguagem, como: 1. Math: Objeto global que agrupa propriedades e métodos para funções e constantes matemáticas (ex: Math.PI, Math.random()). 2. Date: Construtor usado para criar e manipular instâncias que representam datas, horários e fusos horários. 3. JSON: Objeto que fornece métodos estruturados para converter dados entre strings de texto e objetos JavaScript (JSON.parse() e JSON.stringify()).
