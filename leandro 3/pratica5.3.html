P5.3: O Efeito do Hoisting (Elevação)

O JavaScript move todas as declarações de variáveis com var para o topo do seu contexto de execução (neste caso, o início da função) antes de executar qualquer linha de código.

Abaixo está a reescrita de como o motor do JavaScript interpreta, reorganiza e executa o código internamente:

function exibeMensagem() {
    var mensagem; // 1. A declaração é elevada para o topo e inicia com o valor 'undefined'

    if (true) {
        mensagem = 'Minha mensagem'; // 2. A atribuição do valor permanece no local original
        console.log(mensagem);       // Exibe: 'Minha mensagem'
    }
    
    console.log(mensagem);           // Exibe: 'Minha mensagem' (Acessível porque o escopo pertence à função)
}
Verificação no Console: Abra o console do navegador (F12) para ver que a função acima é executada perfeitamente, provando que a variável mensagem existe em todo o corpo da função.
