• Versão de Introdução: As classes foram introduzidas oficialmente em 2015, na versão ECMAScript 6 (ES6). • Açúcar Sintático (Syntactic Sugar): Significa que a palavra-chave class é apenas uma nova sintaxe (uma "roupa mais bonita" e familiar) criada para escrever o código de forma mais simples e legível. O JavaScript não ganhou um novo sistema de orientação a objetos. Por baixo desse visual elegante, a linguagem continua usando exatamente o mesmo sistema baseado em funções construtoras e cadeia de protótipos que você estudou no bloco T7.
