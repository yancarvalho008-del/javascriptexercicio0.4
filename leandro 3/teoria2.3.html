appendChild() (ou appendChild) é usada para inserir, e removeChild() (ou removeChild) é usada para remover um elemento do DOM. • Inserção: elementoPai.appendChild(elementoFilho) • Remoção: elementoPai.removeChild(elementoFilho) Atualmente, existem métodos mais diretos que podem ser chamados no próprio elemento ou que facilitam a sintaxe: • elementoPai.append(elementoFilho): Permite inserir múltiplos elementos ou textos de uma vez. • elementoFilho.remove(): Remove o elemento diretamente, sem precisar referenciar o elemento pai.
