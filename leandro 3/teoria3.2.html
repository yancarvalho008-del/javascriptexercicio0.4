• elemento: É o objeto HTML alvo que vai receber o ouvinte. Representa o elemento da página (como um botão, um formulário, uma imagem ou até a janela inteira do navegador) que você deseja monitorar. • evento: É o gatilho textual que o navegador deve detectar. É uma string que define qual ação será monitorada (por exemplo, 'click' para um clique de mouse, 'keyup' para quando uma tecla é solta, ou 'submit' para o envio de um formulário). • funçãoDeResposta: É o bloco de código (callback) executado quando o gatilho dispara. É a função que define o que deve acontecer imediatamente após o evento ocorrer no elemento selecionado.
