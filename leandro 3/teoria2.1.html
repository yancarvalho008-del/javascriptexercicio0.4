O método document.createElement() serve para criar dinamicamente um novo elemento HTML na memória do navegador utilizando JavaScript. Após a criação, esse elemento pode ser manipulado (adicionando textos, classes ou atributos) e inserido na página web. Como argumento, você deve passar uma string com o nome da tag HTML que deseja criar (por exemplo: 'div', 'p', 'button', 'span'). Exemplo createElement
